## فكرة التطبيق

سينمانا سوه يجمعك بأصدقائك داخل غرف مشاهدة خاصة. افتحوا نفس الفيلم أو الحلقة، وشاهدوا بتزامن مع دردشة كتابية وصوتية داخل الغرفة.

## الميزات

- غرف خاصة مع رابط دعوة وموافقة المضيف على الدخول.
- مزامنة التشغيل والإيقاف والتقديم بين المشاركين.
- دردشة نصية واتصال صوتي، مع كتم المايك وضبط الصوت.
- ترشيحات وتصويت لاختيار فيلم الليلة وقائمة مشاهدة مشتركة.
- تحديد موعد للسهرة وحفظه بالتقويم.
- تفاعلات مباشرة وطلب استراحة بموافقة المضيف.
- تخصيص اسم الغرفة وصورتها وألوانها والخط والشفافية.
- بطاقة مشاركة للسهرة، وإدارة المشاركين من داخل الغرفة.
- تحديثات أونلاين وتنبيه عند توفر إصدار جديد.

## التحميل والاستخدام

1. حمّل ملف **Cinemana-Soah-1.0.0.apk** من الرابط أعلاه وافتحه لتثبيته. قد يطلب أندرويد السماح بالتثبيت من المتصفح.
2. افتح التطبيق واضغط زر **سوه** لإنشاء غرفة.
3. شارك الدعوة مع أصدقائك ووافق على دخولهم.
4. افتحوا نفس الفيلم أو الحلقة وابدؤوا المشاهدة سوه.
